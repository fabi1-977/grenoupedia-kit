# UI kit — Grenoupedia recette

Ficha de receta en francés (La Ligne), con 4 pantallas conmutables: la ficha web y los formatos IG 4:5, Reel 9:16 y LinkedIn 1:1.
- `data.js`: receta de ejemplo (cuisses en persillade). Sustitúyelo por la salida de la skill recetas-grenoucerie.
- `RecipePage.jsx`: cabecera, selector de corte, meta, hero, barra lateral (sommaire, fiche technique, accords, bloque chef) y cuerpo didáctico.
- `SocialFormats.jsx`: los tres formatos derivados.
Solo compone componentes de `components/`. El logotipo no está disponible: se muestra «GRENOUCERIE» en texto plano.
